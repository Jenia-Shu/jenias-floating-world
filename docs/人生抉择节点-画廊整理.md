## 1. 判据（用户这条需求给的新定义）

一个画廊条目能当「人生抉择节点」，当且仅当两条同时成立：

1. 它是一个**具体的、当时可以选另一边的动作**（不是状态、不是结果）；
2. **反事实成立**：如果没这么选 / 没这么做，后面那些「以这个身份才可能出现」的画廊条目全部不成立，故事也就**没法顺着画廊继续走下去**。

由此排除「结果 / 记录 / 心境 / 回声」——它们是选择之后长出来的东西，倒过来当分岔口，因果就反了。

与 14:35 已定的硬规矩一致：选项必须是会改变走向的具体事件；「要不要写一封信」这类小事不算（`letter` 被用户当面否掉：「跟人生节点关系差的有点远了」）。
