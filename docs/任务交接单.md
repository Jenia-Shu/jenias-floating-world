### A1 · SPA 静态构建 ✅ 已完成（2026-11-07，实际结果见 `任务清单.md` A1）
```
【任务 A1｜SPA 静态构建】

3. 跑 npm run build，看实际产物目录（dist 还是 .output/public），把真实路径记下来。
4. 起静态服务（npx serve <产物目录>）打开，确认欢迎页和 3D 世界都能进。

验收：产物里没有 server/ 目录；静态服务下 Enter 能进世界；控制台无 404。
```
