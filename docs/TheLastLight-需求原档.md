### 为什么它不会和前两款重复？

| 游戏             | 核心体验     | 玩家在做什么       |
| -------------- | -------- | ------------ |
| World Explorer | 认识 Jenia | 回答问题、了解她的世界  |
| Tiny Maze      | 探索与解谜    | 操控公主、寻找出口    |
| The Last Light | 感悟与告别    | 体验场景、留下自己的思考 |

三款游戏的体验分别是：了解一个人 → 探索一个世界 → 带着一点感悟离开。

而且第三款不再需要复杂的地图、题库、随机机制和分支剧情，开发难度也能控制得低很多。

### 我想先确认一个关键方向

最后一款游戏的第三幕，你更希望访客留下什么？

A. 一句话：从几句关于人生的文字中，选择一句带走。

B. 一个愿望：选择一个自己希望未来保持的品质或方向。

C. 一份纪念卡：把整个 Fun Zone 的经历和自己的选择汇总成一张卡片。

D. 不留下具体东西：让整个体验本身成为一段安静、有意义的告别。

确认选择

我个人比较倾向 C：它能让三款游戏真正形成一个完整的整体，而不是三个互不相关的小游戏。
