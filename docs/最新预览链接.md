### 怎么看（重要：解锁链）

站点的解锁顺序是 `我的世界 → 作品集 → 收藏 → 一封信的岛 → 乐园`，一座岛要访问过前一座才开放。

- 你之前一直用 `?world=1` 看这个半成品，浏览器里通常已有访问存档，打开就能看到全部岛。
- 如果某座岛显示「锁」：按上面顺序把前三座各点进去一次，再回来点「一封信的岛」。
- `?world=1` 是**绕过登录表**的调试入口，没有这个参数会先看到登录表单（B1 还没拆）。
- 想看边牧送信动画：存档里前三座已访问、且漂流瓶状态不是 `read` 时，回到地图会播放；想重看可清掉浏览器里该站点的 localStorage 再刷新。

4. 若换了一台机器：先 `git clone` / 拉最新 `main`，`npm install`，再 `npm run dev`；记录都在仓库内 `docs/`。
