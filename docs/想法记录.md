### 长需求里明确写下的硬性细节

- 边牧**不要**加按钮、标记、交互图标；真正可点的是漂流瓶。但边牧仍是**可点击的真实 3D 模型**，首次点击触发「小狗追踪员」徽章，之后不重复发放。
- 信件第一人称，不像系统通知，不假装认识访客；是「世界的主人留给每一位偶然到访者的话」。
- 信件底部按钮「收好这封信，继续探索」；信纸折回小木箱，之后能再次打开阅读。
- 结尾是**自然的电影式转场**，不是突然跳页：边牧起身 → 朝木桥跑几步 → 回头等 → 访客点「跟上它」→ 镜头沿桥前进、云雾散开、摩天轮出现 → 进入 Fun Zone。
- 所有内容不需要联网或后端，静态站用前端交互 + 本地存储实现。

Dear Explorer,

很高兴你能来到这里。

— Jenia
