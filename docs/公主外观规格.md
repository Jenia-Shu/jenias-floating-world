## 三、和现有 `CollieBody` 的差距（带行号，可直接照着改）

现有模型在 `src/components/world/collie.tsx:93-187`，`src/components/fun/scene/Princess.tsx:15` 直接复用了它。全项目**没有任何 glb/gltf/骨骼动画**，都是 `sphereGeometry` / `capsuleGeometry` / `coneGeometry` 拼的。

| 部位 | 现有代码 | 与照片的差距 | 建议方向（不写代码，只给口径） |
|---|---|---|---|
| **额头白纹** | `:117-121` 注释 `the white blaze that makes a collie a collie`；白色椭球 `scale=[0.42,0.86,0.5]`、`r=0.076` → 粗算全宽 ≈ 0.064；头 `:113-116` `scale=[0.86,0.82,0.96]`、`r=0.095` → 全宽 ≈ 0.163，**白纹约占头宽 39%**，且严格居中 | 🔴 **正好踩中需求点名禁止的「额头一大片宽白色毛发」**。照片是约 1/10 的细线 | 把白纹横向收窄到现在的 **1/3 左右**，改成上细下略宽的一条，并给一个小的 x 偏移 / 轻微倾斜，让它不是死板居中 |
| **耳朵** | `:138-146` 注释写的是 `semi-pricked ears`（半立耳）；`coneGeometry`，`rotation z = ±0.34`（约 ±19.5° 外倾），光滑锥面 | 🔴 照片是**完全直立**的尖耳，还带羽状长毛；现在的半立 + 外倾光滑锥体接近需求禁止的「不自然蝙蝠形象」 | 立直（外倾角压到很小或 0），耳片改薄一点、加耳缘 / 耳内的浅色长毛片；不要做成大三角扇面 |

## 四、改模型会牵动谁（开工前必须知道）

`CollieBody` 是**全站共用**的，改它一次会同时影响：

1. `src/components/world/collie.tsx` — 主岛巡逻的边牧（可点击给「小狗追踪员」徽章）
2. `src/components/world/CollieDelivery.tsx` — 漂流瓶岛的边牧送信动画（叼瓶、放瓶、坐下摇尾）
3. `src/components/fun/scene/Princess.tsx` — Fun Zone 的公主（World Explorer 的 NPC，将来是 Tiny Maze 的主角）

而且 `Princess.tsx` 所在的 `src/components/fun/` **正是另一个窗口正在写入的目录**（14:09 刚写 `FunZonePage.tsx`，14:11 又改 `WorldMap.tsx` / `WorldPage.tsx`）。现在动角色模型会同时踩到并行边界和三处动画的回归测试。
